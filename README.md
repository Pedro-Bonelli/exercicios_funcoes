# Exercícios de funções em C

Programas independentes sobre funções em C, distribuídos entre `fun01.c`, outros arquivos `fun*.c` e `func_teste.c`.

## Estrutura

- Arquivos `.c`: exercícios independentes (ou o programa indicado acima).
- Pastas `Lista_Exercicios/`, `Testes/` ou `output/`, quando presentes: organização dos códigos e artefatos.

## Como executar

Requisito: GCC configurado no terminal.

```bash
git clone https://github.com/Pedro-Bonelli/exercicios_funcoes.git
cd exercicios_funcoes
gcc fun01.c -o programa
./programa
```

No PowerShell do Windows, execute `./programa.exe` (ou `.\programa.exe`). Cada arquivo `.c` é um exercício independente, salvo indicação no próprio código.

## Observações

Há arquivos `.exe` versionados, mas compile os `.c` no seu PC para produzir executáveis próprios.
